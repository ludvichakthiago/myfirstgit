Etapa 8:
Perguntas:
• Qual é a diferença entre Working Directory, Staging Area e Repository? 
Working Directory é onde o dev trabalha e modifica os arquivos
Staging Area é a área onde selecionamos quais alterações farão parte no próximo commit.
Repository é o local no git onde mantém os commits e históricos de proejtos.

• Qual é a diferença entre git commit e git push?
Git commit é uma snapshot, um ponto de salvamento 
Git push envia os commits para o remote repository.

• É possível realizar vários commits antes de executar um git push? Explique.
Sim, pois os commits são pontos de salvamentos que podem ser feitos quantas vezes necessárias, o git push vai fazer o envio para o remoto podendo ser utilizado apenas uma vez ao fim de todas as alterações.

• Por que é interessante realizar commits pequenos e descritivos? 
Quanto mais descritivo e acertivo for, mais fácil fica a localização no projeto, tanto para acompanhar o histórico das alterações do projeto quando para as futuras alterações e manutenções do mesmo.

• O que acontece com os commits locais quando ainda não executamos o git push?
Ficam salvos apenas na máquina do dev, sem interferir no remote repository.

• Como verificar, pelo Github, se os commits foram enviados corretamente?
Existe um botão dentro do Github chamado Commits que mostra todos os Commits feitos pelo dev.
